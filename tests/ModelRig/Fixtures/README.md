# Synthetic rig test assets

These locally authored models contain a weighted triangle bound to three joints and a second triangle translated four units along X. The two-second Swing clip moves the root one unit along Y and rotates the middle joint 90 degrees around Z. The glTF, GLB, and Collada fixtures also include a separate Grow clip that doubles the tip joint's scale.

The glTF and GLB fixtures share the same geometry and animation data. The ASCII FBX was exported via Assimp, and the Collada export includes explicit animation sources for both clips. The fixtures contain no external textures or geometry.
